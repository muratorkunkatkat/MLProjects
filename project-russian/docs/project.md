# О проекте «SmartCampus»

## Аннотация
**SmartCampus** — это современная система умного расписания и навигации по кампусу университета. Проект направлен на решение проблемы поиска нужных аудиторий и оптимизации времени студентов и преподавателей.

## Цель проекта
Разработать удобную платформу, которая объединяет актуальное расписание занятий с интерактивной картой университетского кампуса.

## Задачи
1. Сбор и анализ данных о расписании и расположении аудиторий.
2. Проектирование пользовательского интерфейса (UI/UX) для мобильных устройств.
3. Разработка базового прототипа системы.
4. Интеграция с существующими информационными системами университета.

## Актуальность
Каждый семестр студенты (особенно первокурсники) сталкиваются с трудностями при поиске нужных аудиторий и лабораторий. Единое приложение с расписанием и картой кампуса значительно снизит стресс и повысит пунктуальность обучающихся.
