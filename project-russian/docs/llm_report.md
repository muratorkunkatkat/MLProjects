# Отчёт о прохождении онлайн-курсов по искусственному интеллекту (LLM)

## 1. Введение
В рамках прохождения проектной (учебной) практики были изучены современные технологии искусственного интеллекта, в частности, большие языковые модели (LLM). Цель изучения — понимание принципов работы нейросетей, этических аспектов их применения и освоение навыков составления эффективных запросов (промпт-инжиниринг).

## 2. Пройденные курсы
Для освоения материала были выбраны следующие образовательные ресурсы:
1. **Hugging Face NLP Course**
   - **Ссылка:** [https://huggingface.co/learn/nlp-course](https://huggingface.co/learn/nlp-course)
   - **Тематика:** Базовые принципы обработки естественного языка (NLP), архитектура Transformer, токенизация и работа с открытыми моделями.
2. **Основы промпт-инжиниринга (Введение в ChatGPT и LLM)**
   - **Тематика:** Правила составления эффективных запросов, контекстное окно, few-shot prompting, этика использования ИИ при написании кода.

## 3. Полученные знания
В ходе изучения материалов были получены следующие теоретические знания и практические навыки:
- **Архитектура Transformer:** Изучены механизмы внимания (Self-Attention), позволяющие модели анализировать контекст всего предложения, а не отдельных слов.
- **Промпт-инжиниринг:** Освоены методы точной постановки задач для ИИ. Стало понятно, что добавление ролевых установок (например, "Действуй как Senior Frontend Developer") и четких ограничений значительно улучшает результат генерации.
- **Этические аспекты:** Изучены проблемы галлюцинаций (выдачи ложной информации за правду) и важность верификации ответов, сгенерированных нейросетью.

## 4. Применение LLM при выполнении практики
Полученные знания активно применялись на всех этапах выполнения текущей проектной практики:
1. **Генерация и структурирование Markdown-документации:** ИИ использовался для создания черновых вариантов документации, проверки орфографии и форматирования таблиц.
2. **Написание кода для сайта:** При разработке статического сайта (`site/`) LLM помогла сгенерировать базовый CSS-шаблон (Flexbox-верстка для навигационного меню) и HTML-разметку, что существенно сократило время на рутинную работу.
3. **Разработка бота (Вариативная часть):** Знания по LLM легли в основу концепции вариативной части — умного Telegram-бота для проекта SmartCampus.

## 5. Заключение
Использование больших языковых моделей является мощным инструментом, который значительно ускоряет процесс разработки программного обеспечения и написания документации. Пройденные курсы позволили не только понять механику работы современных нейросетей, но и эффективно применить их на практике.
