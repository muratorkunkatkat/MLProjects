# Техническое руководство: Разработка интеллектуального Telegram-бота «SmartCampus» с нуля

## 1. Введение и Архитектура системы
Данное руководство описывает процесс создания минимально жизнеспособного продукта (MVP) — Telegram-бота для системы навигации и расписания кампуса «SmartCampus». Бот разработан на языке программирования Python с использованием библиотеки `pyTelegramBotAPI` и имитирует интеграцию с большой языковой моделью (LLM) для распознавания намерений пользователя.

### Архитектурная схема взаимодействия:
1. **Пользователь** отправляет сообщение в текстовом интерфейсе Telegram.
2. **Telegram Bot API** перенаправляет запрос на сервер через Long Polling.
3. **Модуль обработчиков (Handlers)** классифицирует входящий текст.
4. **Имитационный движок LLM (Intent Parser)** анализирует ключевые токены и семантику запроса.
5. **База знаний / Ответ сервера** формирует форматированный Markdown-ответ и отправляет его обратно пользователю.

## 2. Пошаговая инструкция по развёртыванию

### Шаг 1: Регистрация бота и получение токена
1. Откройте Telegram и найдите официального бота **@BotFather**.
2. Отправьте команду `/newbot` и следуйте инструкциям (задайте имя бота и уникальный юзернейм, заканчивающийся на `_bot`).
3. Скопируйте сгенерированный **API Token** (строка вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### Шаг 2: Подготовка окружения разработки
Убедитесь, что на вашем компьютере установлен Python версии 3.8 или выше. В терминале выполните команду для установки пакета работы с Telegram API:
